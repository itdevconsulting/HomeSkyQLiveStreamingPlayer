# Home Sky Q Player add-on

Home Assistant add-on wrapper for [Home Sky Q Live Streaming Player](https://github.com/itdevconsulting/HomeSkyQLiveStreamingPlayer).

Install this GitHub repository as a custom add-on store, then install **Home Sky Q Player**. Full steps are in [DOCKER.md](../DOCKER.md).

The add-on uses host networking and exposes the player at `http://HOME_ASSISTANT:5221`.
